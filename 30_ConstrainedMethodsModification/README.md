### КТ №30 Модификация обобщённых методов
#### Вариант 2. Расширения с ограничением

1. Статический класс с методом расширения T? FindMax<T>(this IEnumerable<T> source) where T : IComparable<T>, возвращающим наибольший элемент последовательности.
2. Метод расширения void PrintAll<T>(this IEnumerable<T> source, string prefix), выводящий каждый элемент с заданным префиксом (без ограничения типа).
3. Реализуйте собственный класс или структуру, реализующую IComparable<СвойТип>.
4. Продемонстрируйте FindMax на встроенном типе (List<int> или List<double>) и на коллекции вашего собственного типа из пункта 3.
5. Продемонстрируйте PrintAll на любой из этих коллекций.

(В качестве своего класса взяла класс Player с именем и очками)

| Действие | Ожидаемый результат |
| :--- | :--- |
| `new List<int> { 5, 9, 2 }.FindMax()` | `9` |
| коллекция собственного типа `.FindMax()` | элемент с наибольшим значением по вашему критерию сравнения |
| `PrintAll` с префиксом `"Элемент: "` | каждая строка вывода начинается с этого префикса |
